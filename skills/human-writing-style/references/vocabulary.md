# Vocabulary reference — AI-overused words and phrases

## How to use this file

Word-swapping is necessary but not sufficient. A single flagged word means nothing; a dense cluster of
them is one of the strongest tells there is. But removing the words without fixing the substance (see
the substance pass in SKILL.md and section B of `patterns.md`) just produces cliché-free AI text that
still fails on content. Fix the vocabulary *and* the thinking.

**Hard ban** = don't use in output.
**Caution** = fine in isolation; a red flag when it appears alongside other items here.

Two rules that prevent false positives:

- **A banned word does not ban its synonyms.** "underscore" is overused; "underline" and "emphasize"
  are not automatically suspect. Fix the specific words, not every formal-sounding word.
- **Context decides.** "underscore" meaning a literal underline mark, or incidental music, is fine;
  only the figurative "underscores its importance" is the tell. "Has been featured" (past perfect) is
  normal; "boasts / features" as a fancy "has" is the tell.

The overused set also shifts over time, so match the era you're checking against:

- **2023–mid-2024 (GPT-4):** delve, boasts, bolstered, crucial, emphasizing, enduring, garner,
  intricate/intricacies, interplay, key, landscape, meticulous, pivotal, underscore, tapestry,
  testament, valuable, vibrant.
- **Mid-2024–mid-2025 (GPT-4o):** align with, bolstered, crucial, emphasizing, enhance, enduring,
  fostering, highlighting, pivotal, showcasing, underscore, vibrant.
- **Mid-2025 on (GPT-5):** emphasizing, enhance, highlighting, showcasing — plus the whole
  notability/attribution cluster (independent coverage, trade publications, active social media
  presence, profiled in). "delve" dropped off sharply after 2024, so its presence now points to older
  output or a smaller/derivative model.
- **Grok is idiosyncratic:** overuses pseudo-scientific words — causal, empirical, correlate — and
  still leans on "underscore" as of 2026.

## English

### Hard ban — overused across eras

| Avoid | Replace with |
|---|---|
| delve (into) | examine, look at, explore, go into |
| tapestry (figurative) | (cut the metaphor; be specific) |
| landscape (abstract: "the evolving landscape of") | field, sector, situation, context |
| testament (to) | proof of, evidence of, shows |
| underscore / underscores (figurative) | shows, confirms, reveals, makes clear |
| highlight (as verb meaning "emphasize") | show, reveal, point to, note |
| showcase | show, demonstrate, display |
| pivotal | key, decisive — or be specific about *why* |
| crucial | important, necessary, required |
| vibrant | lively, busy, active — or be specific |
| foster / fostering | build, encourage, support, create |
| garner | win, earn, attract, get |
| bolster | strengthen, support, reinforce |
| meticulous / meticulously | careful, thorough — or cut it |
| intricate / intricacies | complex, detail, specifics of |
| interplay | relationship, interaction, tension between |
| enduring | lasting, ongoing, persistent |
| valuable insights | (cut the phrase; state the insight) |
| indelible mark | lasting effect, permanent change |
| deeply rooted | long-established, historically tied to |
| focal point | centre, focus |
| boasts (meaning "has") | has, includes |

### Hard ban — significance / legacy boilerplate

| Avoid | Notes |
|---|---|
| stands as a reminder that | delete |
| serves as a testament to | delete |
| plays a vital / crucial / pivotal role | rewrite with specifics |
| underscores its importance / significance | cut; show the importance instead |
| reflects broader trends | cut unless you name the trend with evidence |
| symbolizing its ongoing / enduring / lasting | cut |
| contributing to the [broader field / community] | cut unless specific and sourced |
| setting the stage for | say what actually happened next |
| marking / shaping the | rewrite |
| represents a shift | say what changed, concretely |
| key turning point | rewrite; specify what changed and when |

### Hard ban — notability / attribution cluster (current-era tell)

| Avoid | Notes |
|---|---|
| independent coverage | echoes Wikipedia's guideline wording; summarize what sources said |
| local / regional / national media outlets | name the outlet and what it reported |
| trade publications / music / tech outlets | same |
| maintains an active social media presence | cut; it says nothing |
| profiled in / featured in (as a notability claim) | summarize the coverage instead |
| significant, substantial, secondary coverage | don't assert it; demonstrate it |

### Caution — avoid dense clusters

additionally / moreover (sentence-openers), align with, boasts, crucial, emphasizing, enhance, key
(adjective), meticulous, notably, pivotal, showcase, vibrant, valuable.

### The "concrete" comment tell

In argument or talk-page writing (not article prose), AI defends itself by demanding "concrete
evidence" or "concrete examples", or insisting there is no "concrete" proof. Overuse of "concrete" as
an adjective in a dispute is a specific marker. Also common in these contexts: assurances that the
writer is "ensuring" the content "adheres to / aligns with / complies with" the rules, and accusing
critics of relying on "speculation" about writing style.

## Other languages

The pattern is identical everywhere: abstract nouns of importance, participial significance tags
(-ing / -ant / -ando), notability assertions, and challenge-outlook endings. Apply the English test:
would this sentence stay true of almost any subject after a one-word swap? If yes, rewrite it. And
remember the American-English default — a text whose spelling variety doesn't match the author's
region or the topic's national ties is a mild additional signal.
